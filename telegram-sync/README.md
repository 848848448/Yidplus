# YID PLUS — טעלעגראַם־טשענעל סינק · פֿירונג

דער סקריפּט (`yidplus_sync.py`) לויפֿט אויף **דײַן** טעלעגראַם־אַקאַונט, קוקט אויף דײַנע
פּובליקע טשענעלס, און שיקט יעדן נײַעם פּאָסט צו YID PLUS.

---

## שריט 1 — באַקום דײַן טעלעגראַם API־קיי (איין מאָל)

1. גיי צו **https://my.telegram.org** און לאָגירן מיט דײַן טעלעגראַם־נומער.
2. דריק **"API development tools"**.
3. שאַף אַן אַפּ (סתּם אַ נאָמען, למשל "yidplus"). 
4. קאָפּיר די צוויי זאַכן: **api_id** און **api_hash**.

## שריט 2 — שטעל דעם סוד־קיי אין Cloudflare

1. אין Cloudflare → דײַן Pages פּראָיעקט → **Settings → Environment variables**.
2. לייג צו אַ נײַעם: 
   - נאָמען: `TELEGRAM_INGEST_SECRET`
   - ווערט: עפּעס לאַנג און סודותדיק (למשל `yp_9f3kZ...` — טראַכט אויס עפּעס).
3. **דער זעלבער** סוד גייט אויך אין דעם סקריפּט (שריט 3).

## שריט 3 — פֿיל אויס דעם סקריפּט

עפֿן `yidplus_sync.py` און פֿיל אויס דעם `CONFIG`־טייל:
```
API_ID        = 123456                (פֿון שריט 1)
API_HASH      = "..."                 (פֿון שריט 1)
PHONE         = "+1..."               (דײַן טעלעגראַם־נומער)
INGEST_SECRET = "..."                 (דער זעלבער ווי אין Cloudflare)
CHANNELS      = ["allsingersinone"]   (דײַנע פּובליקע טשענעלס)
```

## שריט 4 — לויף עס

**אויף דײַן אייגענעם קאָמפּיוטער** (דער גרינגסטער אופֿן צום אויספּרוּוון):
```
pip install telethon requests
python yidplus_sync.py
```
דער ערשטער מאָל וועט עס דיך פֿרעגן אַ קאָד וואָס טעלעגראַם שיקט דיר — טיפּ עס אַרײַן (איין מאָל).

דעמאָלט וועט עס:
- ✅ ברענגען די לעצטע 20 פּאָסטן פֿון יעדן טשענעל
- ✅ הערן אויף נײַע פּאָסטן און זיי שיקן צו YID PLUS

**וויכטיק:** דער סקריפּט מוז **בלײַבן לויפֿן**. אויב דו פֿאַרמאַכסט אים (אָדער דײַן קאָמפּיוטער גייט אויס), שטעלט זיך אָפּ די סינק ביז דו לויפֿסט אים ווידער.

## אויף אַ אומזיסטן האָסט (אַנשטאָט דײַן קאָמפּיוטער)

אויב דו ווילסט אַז ס'זאָל לויפֿן 24/7 אָן דײַן קאָמפּיוטער — נוץ **Replit** (אומזיסט, קיין קרעדיט־קאַרטל):

1. גיי צו **replit.com**, שאַף אַ קאָנטע, נײַער **Python Repl**.
2. אַרויפֿלאָד `yidplus_sync.py` (אָדער פּעיסט דעם קאָד).
3. אין Replit's **Secrets** (🔒) — אָדער סתּם אין דעם קאָד — שטעל דײַנע קיז.
4. דריק **Run**. דער ערשטער מאָל — טיפּ דעם טעלעגראַם־קאָד אין דער קאָנסאָל.

⚠️ **חסרון:** אומזיסטע Replit **שלאָפֿט אײַן** ווען נישט אין באַניץ. דעמאָלט זעט עס נישט
נײַע פּאָסטן ביז ס'וועקט זיך אויף. פֿאַר אַ **פֿאַרלאָזלעכן** 24/7 סינק דאַרף מען אַ VPS (~$5/חודש).
